# AGNI-SMART

## Smart Solar-Powered Agarbatti Drying & Packaging System

AGNI-SMART is a low-cost smart drying and packaging system designed
to improve the efficiency of agarbatti production.

## Features

- Solar-powered drying
- Temperature and humidity monitoring
- Automated drying control
- Weight-based moisture monitoring
- IoT monitoring
- AI/ML-based drying prediction
- Battery backup

## Technologies Used

- ESP32
- DHT22
- Load Cell
- IoT
- AI/ML
- Solar Energy
